# Роберт, есть вопрос.

Шуточный сайт в тематике Dota 2 и GTA V RP. Чистые HTML, CSS и JavaScript, без сборки и зависимостей.

## Локальный запуск

Из папки репозитория: `python3 -m http.server 8000 --bind 0.0.0.0`.

Кнопка «Да» убегает при приближении курсора и при касании на телефоне. Она исключена из Tab-навигации. «Нет» подтверждает легендарность Роберта.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
После отправки файлов в `main` workflow `.github/workflows/pages.yml` опубликует сайт.
Ожидаемый адрес: https://astylezzz.github.io/my-first-site/ (станет доступен после успешного деплоя).

Используются системные шрифты; внешних ресурсов и запросов нет.
